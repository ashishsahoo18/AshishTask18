# Colour Boxes and Greeting

A simple interactive page built with HTML, CSS and JavaScript.

## Features
- Header that says "Hello" initially
- Four boxes labelled red, blue, green and yellow
- Clicking a box fills it with the colour named in it (DOM manipulation)
- Input field + "Greet" button changes the header to "Hello, [name]"
- Empty input resets the header to "Hello"

## Files
- `index.html` – page structure
- `style.css` – styling and layout
- `script.js` – click and greeting logic
- `Readme.md` – this file

## How to run
Open `index.html` in a browser.
